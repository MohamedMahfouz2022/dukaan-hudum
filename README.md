## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/MohamedMahfouz2022/dukaan-hudum.git
```

Go to the project directory:

```bash
cd dukaan-hudum
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
